The simulated controller reads a forward LiDAR sector and left/right clearances, then publishes bounded linear and angular speeds.

How to use: Start the simulation, watch the scan rays react to obstacles, and use Add obstacle to change the route. This is a self-contained 2D educational model; it visualizes the ROS 2 /scan → controller → /cmd_vel flow but does not connect to a live ROS graph or Gazebo.
